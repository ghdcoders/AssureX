# AI Usage Declaration
**Project:** AssureX Claim Engine  
**Team:** GHD Coders (Aptech Gulshan-e-Hadeed)  

In compliance with the Techwiz 7 Competition Integrity and Anti-Shortcut Requirements, the following declares the use of AI tools during the development of the AssureX Claim Engine.

### 1. Tool Details
* **Name of the AI Tool:** Gemini
* **Purpose of Use:** UI/UX refinement, CSS troubleshooting, Streamlit layout optimization, and documentation structuring.
* **Prompt or type of assistance requested:** Assistance was requested to convert the functional Streamlit dashboard into a professional, SRS-aligned light theme, fix HTML/CSS rendering bugs (e.g., empty div boxes and image loading errors), and format the README.md file.

### 2. Implementation & Verification
* **Files or Modules Affected:** 
  * `app.py` (Frontend UI styling, layout containers, base64 image encoding)
  * `README.md` (Project documentation structure)
* **Modifications performed by the team:** The team developed the core Python classification model, integrated the Google Teachable Machine model, built the business rule engine, and designed the initial Streamlit logic. The AI-provided CSS and layout adjustments were manually reviewed, modified to fit local file paths (e.g., handling `.png.png` asset extensions), and integrated into the final codebase. The final claim decision logic relies entirely on the team's trained models and rule engine, not generative AI APIs.
* **Testing completed by the team:** The team performed local execution testing, UI layout verification across different screen sizes, file path resolution testing for assets, and full end-to-end claim evaluation testing to ensure the AI-styled UI did not interfere with the inference engine's accuracy.
* **Verified by:** Abdul Sattar (Lead Software Engineer)
